# 加油站班次交接

- 行业：石油
- 技术栈：Vue3、Vite、TypeScript、Pinia、Element Plus
- 启动：`npm install && npm run dev`
- 构建：`npm run build`
- 逻辑冒烟：`node_modules/.bin/esbuild scripts/smoke.ts --bundle --platform=node --format=esm --outfile=/tmp/smoke.mjs && node /tmp/smoke.mjs`

数据保存在浏览器 localStorage（`gas-station-handover-v1`），纯前端闭环，方便后续替换为接口、权限等能力。

## 交接流程（对应业务规则）

1. **草稿阶段 — 交班人继续处理**
   - 把油款、设备异常、顾客退款等未结事项录入交接单，可随时更新进展（待处理/处理中/待接棒）。
   - 定稿前责任留在原班次，交班人可继续跟进、补录或移除事项。
2. **定稿 — 未结事项锁定**
   - 定稿后事项不可再改，交班人停止处理，等待接棒人逐项处置。
3. **逐项接收 / 退回 — 接棒人**
   - 每项单独「接收」或「退回」；退回必须填写原因。
   - 接收：责任转到新班次；退回：留在原班次继续处理。
   - 必须逐项处理完毕才能「整单签收」；签收后责任正式转移。
4. **定稿后的改动 — 一律重新发起，原记录保留**
   - **补记**：新发现事项 → 生成新的定稿单交同一接棒班次。
   - **撤销**：对已接收事项发起撤销 → 接棒人同意后事项退回原班次（拒绝则继续留新班次）。
   - **改派**：把事项改派给另一个班次。
   - **退回重交**：针对退回项补充说明后再次交接。
   - 所有重新发起的单据都通过 `parentId` 关联来源单，来源单及全部日志不可改动、永久保留。
5. **关机重开 — 续接而非重开**
   - 页面每次载入自动定位未完成交接单并提示续接；已接收/已退回项及其责任方完整保留，不会被重置。
   - 同一交班班次再次点「发起/续接」时，若存在草稿或定稿未签收的单，直接打开原单，不会重开。
6. **旧班次无单 — 可补开、下次换班补齐**
   - 在「班次管理」里为任意历史班次「补开交接单」（标记为补录），补齐事项后在下次换班时交下一班。

## 代码结构

- `src/types.ts`：交接单、事项、班次、留痕日志的类型定义
- `src/store.ts`：状态机与全部业务规则（定稿、逐项处置、签收、重新发起、持久化）
- `src/components/SheetView.vue`：交接单工作台（事项处置 + 操作栏 + 流转日志）
- `src/components/ReinitDialog.vue`：补记 / 撤销 / 改派 / 退回重交弹窗
- `src/components/SheetList.vue`：单据列表与状态筛选
- `src/components/ShiftManager.vue`：班次管理与旧班次补录
- `scripts/smoke.ts`：核心规则的 35 项纯逻辑冒烟检查
